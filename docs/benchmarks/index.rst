Benchmarks
==========

Reproducible benchmark documentation for the QuantsMind Relational DB.

The benchmark harness lives in the repository's ``benchmarks/`` directory (see
:doc:`the harness overview <harness>` and the R3 results page below). Results
are stored under ``benchmarks/results/`` and contain real measurements only —
never aspirational numbers.
